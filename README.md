# 🧮 Basic Calculator in C

A simple, menu-driven **Basic Calculator** developed using the C programming language. This program performs fundamental arithmetic operations and provides an easy-to-use terminal interface for mathematical calculations.

## 📌 Overview

The Basic Calculator is a beginner-friendly C programming project designed to perform basic mathematical operations based on user input.

Users can select an arithmetic operation, enter two numbers, and instantly get the calculated result.

## ✨ Features

- **Addition:** Adds two numbers.
- **Subtraction:** Calculates the difference between two numbers.
- **Multiplication:** Multiplies two numbers.
- **Division:** Divides one number by another.
- **Modulus:** Calculates the remainder of integer division (if implemented).
- **User-Friendly Interface:** Simple menu-driven terminal navigation.
- **Input Handling:** Accepts user input for mathematical calculations.

## 🛠️ Technologies Used

- C Programming Language
- Standard Input/Output (`stdio.h`)
